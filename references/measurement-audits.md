# 提升声明的审计：把“看起来的收益”拆开

**规则：相对增益（A 比 B 好 x%）只是测量结果，不是机制证据。** 在把它写成结论前，先排除四类**评估设计伪影**——它们都能让一个不工作的机制显得有效，而且每一类都有一个便宜的决定性对照。四类伪影的判据、对照与处置见下表；每一条都来自实际踩过的坑（案例数字见文末）。

## 四类伪影与决定性对照

| 伪影 | 典型表现 | 决定性对照 | 判读 |
| --- | --- | --- | --- |
| ① **冻结/未训练组件** | 被声称承担收益的“共享空间/对齐器/适配器/投影”实际从未被优化 | 审计**实际可训练参数集**（打印 `requires_grad` 的参数名与参数量），再跑一个“该组件可训练”的对照臂 | 可训练后增益消失 → 增益来自拟合能力，不来自被声称的机制 |
| ② **退化任务** | 标签本身就是捷径属性：来源、域、模态、架构 id、批次号 | **标签置换**：在来源/分支间做无不动点置换，任务难度不变、只改标签对应关系 | 增益不变（±10 个百分点内）→ 增益度量的是“识别来源”，不是任务本身 |
| ③ **模型没用目标** | 输出与目标无关，却仍“赢”过基线 | **目标随机化**：逐样本给随机标签（模型不可能解出） | held-out 数字与对齐目标**逐位相同** → 模型从未使用目标 |
| ④ **缺平凡基线** | 只报相对增益，不报绝对误差 | 加**预测全零/多数类/上一帧**的平凡基线 | 绝对误差须显著低于平凡基线；否则“赢家”和“输家”都很差，比较无意义 |

处置顺序：先 ④（有没有意义）→ ①（机制是否被训练）→ ②③（任务是否退化）→ 再谈机制解释。③ 最便宜（一行改标签），优先做。

### 平凡基线是一条阶梯，不是一档

“预测全零”只是最弱的一档。**零参数对照里还有更强的：预测训练集的类别均值。**

目标若是块状 one-hot（每样本恰有一个宽度 `d/K` 的区段置 1），两条基线都是**精确等式**，
不需要估计：

| 零参数预测器 | 解析 MSE |
| --- | --- |
| 恒输出全零 | `1/K` |
| 每维输出类别均值 `1/K` | `(K−1)/K²` |

`K=6`：`0.1667` vs `0.1389`（相差 20%）。实测某机制得 `0.1617`——
**比全零好 3.0%，但比预测均值差 16.4%**。用全零当基线会得到“低于基线”的错结论；
用预测均值才知道它只是学会了“输出一个接近常数的东西”。

纪律：

- 报基线时至少两档：**全零 / 多数类** 与 **无参数最优常数**。
- 能解析算出的基线就用解析值（写进产物，不靠跑）；它是唯一不会被实现细节污染的量。
- 换损失函数时基线要跟着换：同一机制的“最优常数”在不同评价器下不是同一个预测器。
  一个便宜的交叉校验：某档的“无信息预测”与另一档解析基线**应当撞到同一个数**——
  撞不上说明两档的口径没对齐。

## 预登记：把判据写在结果之前

- 每条判据写全：编号、可执行陈述、阈值、种子数、“不通过时哪条主张回退”。
- **不得事后改判据**。若判据本身设错：保留原判据的失败记录，另给一个**更强、无阈值**的对照，并写明“被推翻的是我的判据，不是被审计的结论”。
- 交付格式固定三态：`判据 | 阈值 | 实测 | 通过/未通过`；未通过的写清推翻了什么。
- 判据要能被**便宜的对照**证伪。反例（真实踩过）：判据写成“随机目标臂里目标类别可解码 ≤ 0.50”，实测 0.58/0.67 未过——原因是**随机线性映射本就保留输入的类别几何**，输出里恒有类别信息；该判据把“输出含类别信息”误当成“模型用了目标”的代理。正确做法是保留失败记录，改用“**逐位相同**”这个无需阈值的对照。

## 独立复算：换掉所有自由变量，只留被审计对象

重跑同一份代码只能查“可复现”，查不出“被实现细节带偏”。**每审换掉全部自由变量**，只保留被审计的模块本身：

| 维度 | 一审 | 二审 | 三审 |
| --- | --- | --- | --- |
| 数据划分 | 换扰动种子 | 未见组合（组合奇偶划分） | 换域（槽位值域分割） |
| 探针 | SGD 逻辑回归 | 闭式岭回归 | 岭回归 + MLP + kNN 三族 |
| 被替换的结构件 | 两层 MLP | LayerNorm+GELU MLP | 残差 MLP + 门控 |
| 种子 | 0–4 | 1000–1004 | 2000–2004 |
| 宽度/容量 | 256 | 128/256/512 | 96/384（与上一审不重叠） |

- 换种子不是形式：它把“结论依赖某次初始化”变成可检验的（≥4/5 seeds 同向）。
- 宽度不重叠顺带测“结论是否只在某个容量成立”。
- 三套实现同向 → 可以说“结论经三套独立实现复现”；**仍不要**写“已证明”。

## 探针纪律

- **单一探针族不是证据**：线性探针读不到非线性可解码的结构（实测：MLP 探针 0.58 vs 线性 0.43）。至少两类（线性 + 非线性/非参数）。
- **同时探“捷径属性”与“目标属性”，报差值**，不要只报高的那个。
- 探针自带自检：可分数据上应高、纯噪声上应接近随机；两者都报。
- 探针自己要训参数时，必须在 `no_grad` 之外；优先用**闭式解**（岭回归）以便确定性复算。

## 正面控制：负面结论需要一条正面量

只证明“这个增益是假的”会让人误读成“什么都没做成”。若声称“共享空间让异构表示相遇”，就直接量它——同一输入经不同分支后的输出一致性（余弦）：

| 空间 | 跨分支一致性 |
| --- | --- |
| 冻结随机 | +0.01 / −0.01（彼此无关） |
| 学到的 | +0.54 / +0.61（确实相遇） |

配一条正面量之后，结论才是“收益来自空间、不来自融合”，而不是“什么都没做成”。

## 容量与对照的纪律

- “非线性 vs 线性”必须**参数量对齐**（实测 <1%），并在单测里对着**真实模块**数参数：公式极易漏项（漏 h² 项偏差 44%，输出层重复计数偏差 6.4%，两次都被单测抓到）。
- 对照臂之间只允许一个差异：换了抬升就固定数据/种子/步数；换了划分就固定模型与优化器。

## 尺子本身会有盲区：换评价器

MSE 是**点估计**：它对“这个模型根本没在建模分布”没有分辨力。实测两个都收敛到很差的模型，
MSE 上的差异只有几个百分点，而其中一个是纯常数预测器。

要判断“机制是否真的学到了结构”，把评价器从一个变成三个，**配对**跑：

| 档 | 额外参数 | 能给的东西 |
| --- | --- | --- |
| MSE（对照） | 0 | 与历史读数可比 |
| 高斯 NLL（逐样本标量 `logvar`） | `d+1` | 分布拟合、可校准性 |
| Cross-Entropy | +1（温度） | 类别后验、准确率 |

四条纪律，缺一条结论就不可信：

1. **配对**：三档共用同一 seed、同一初始化、同一批顺序。任何两档的差异只能来自损失。
   产物里落**初始化哈希**，从产物层证明配对（见 evidence-integrity §5）。
2. **参数等量**：换评价器最容易踩的坑是输出头尺寸悄悄改变参数量，于是“哪把尺子好”
   与“哪个模型大”混在一起。CE 用**块均值池化**而不是另接一个线性头（池化无参数），
   NLL 用逐样本标量方差而不是逐维对角（后者 `+d·h`）。
3. **构造一个跨档可比的标量**：三档的 loss 量纲不同，**不可直接互比**。
   做法是每档都额外报“同一个输出张量经过各自评价器头之后的 MSE”。
4. **输出必须落在同一几何上**：CE 不约束输出幅度，直接取它的 `mse` 会与 MSE 档差一个数量级
   （实测 `1.97` vs `0.153`）。把 CE 输出压到单纯形（block 均值 → softmax → 摊回）之后才可比。

顺带两条判读：

- **head 的线性/非线性是两族**：`concat + 线性层` 与 `add` 头**数学等价**
  （都等于 `f(h) + g(c)`），解不了 XOR。实测 `linear` 头 `0.492`（= 随机），
  `mlp` 头宽度 **2** 即 `1.000`。所以“concat 有用”这个说法必须写成“**concat 之后的非线性**有用”。
- 某档的方差头若在训练集上 `+0.96`、留出集上 `−0.24`（反号），说明它学的是训练集噪声结构，
  不是不确定性 ⇒ 该档的读数在解释时降权，并在报告里写明。

## 容量读数必须与样本量一起报

“这个空间/表示很空”这类结论，在对样本量做扫描之前不要写。

实测两个混杂，任一个都能单独造出“空”的假象：

| 混杂 | 症状 | 处置 |
| --- | --- | --- |
| **样本量太小** | `n=512` 上量得“2560 维只占 33.7 个方向（1.32%）”；`n` 扫 64/128/256/512 得到 20.8/24.7/29.8/33.7，**单调上涨且未饱和** | 报秩必须给 `n`，并对 `n` 做至少 3 档扫描；未饱和就不能说“上限” |
| **组件被冻结** | 特征从预训练模型取出后不再变，测出的秩是**预训练压缩的结果**，不是“空间”的属性 | 要让“空间能不能长”可测，被测组件必须参与训练（适配器/全参/从零各一臂），并在**等参数**下比宽度 |

另外两条与容量有关的方法陷阱：

- **有效秩的口径要写清**：参与率 `(Σσ)²/Σσ²` 与熵有效秩 `exp(−Σp log p)` 对长尾的敏感度不同。
  两者都报，并报“占环境维的比例”，否则“秩=7”在 96 维与 3072 维下是完全不同的意思。
- **极小样本上的相关度量会系统性虚高**：`n≈d` 时朴素 CCA 在**纯独立**随机块上给出
  **29–31** 个“显著”通道（白化把样本噪声白成了信号）。置换零分布有 `+1` 偏差，
  z 检验会把噪声读成 17。可用解法是改用**互协方差谱**并配**解析噪声水平**
  （按列标准化后独立时 `σ = 1/√(n−1)`），再用谱的最优硬阈值数通道；
  纯噪声必须给出 **0** 个通道，这条要写进单测。

## 测量脚本自身的坑（会静默污染结果）

| 坑 | 症状 | 处置 |
| --- | --- | --- |
| 探针写在 `torch.no_grad()` 里 | `element 0 of tensors does not require grad` | 探针移出 no_grad，只把前向放进去 |
| 批量按分支拼接、目标没跟着平铺 | `size of tensor a (384) must match b (128)` | 目标按分支 `cat` 同样份数 |
| 可训练投影在训练循环外算一次 | `backward through the graph a second time` | 每步内重算投影 |
| 留出集“看起来”不相交 | 训练/留出样本撞车（词表重复、槽位复用） | 把集合交集断言写进单测 |
| 参数量公式手写 | 容量没对齐，结论被容量混淆 | 单测数真实模块参数并对齐到 <1% |
| 不同臂给出**逐位相同**的数字 | 误以为是 bug | 这通常是诊断：模型没用到那个变量（见伪影 ③） |
| 只跑一遍 `pdflatex` | 报告页数偏少（没有参考文献页） | 文稿类交付跑完整 `pdflatex → bibtex → pdflatex ×2` |
| 解析式噪声密度在端点有奇性 | 阈值系数被算成 ~0（实测 `0.0036`，正确 ≈0.80），阈值随之失效 | 改用固定种子的蒙特卡洛估同一量；数值积分要在端点加保护并对照已知值 |
| 置换零分布 / z 检验代替噪声水平 | 阈值化后通道数系统性 ±1，或噪声被读成十几个 | 能从标准化方式**解析**推出噪声水平时就不要估；估的时候也要有“纯噪声 → 0”的单测 |

## 案例（同一项目连续六代的审计结果，作为量级参照）

| 代 | 审计对象 | 判决 |
| --- | --- | --- |
| 一审 | “融合优于最优单专家 +26.7%，留出仍成立” | 该 margin 是**源身份识别**的产物：源可解码 1.000 vs 目标类别 0.279（随机 0.125）；绝对误差 4.74，是平凡基线 0.125 的 **38 倍** |
| 二审 | 换实现复算 | 冻结臂里“对齐/标签置换/**目标随机化**”三臂数字**逐位相同**（7.18/6.38/5.78）→ 模型从未使用目标；学到空间后 margin 归零而绝对误差降 ~100 倍 |
| 三审 | 再换实现 + 正面量 | 目标置换 margin 变化 **0.0 个百分点**；有意义空间 margin −0.2%/−0.4%；跨分支一致性 +0.01 → **+0.54/+0.61** |

可辩护的弱主张（比原主张更有用）：**共享空间必须有意义，异构融合才可能工作；一旦空间有意义，融合相对“用好其中一个”优势很小。**


## 远端执行：容器是临时的，状态必须落在外部

审计通常要跑几十格（配置 × 臂 × 种子）。把执行放到远端（Space/Job/临时实例）时，这一节的四条能省掉整轮返工：

| 问题 | 症状 | 处置 |
| --- | --- | --- |
| 容器被回收/重启 | 跑完 15 格等于白跑，进度归零 | **每一格算完立刻把结果写到外部存储**（对象存储/仓库），启动时先读回已完成的格子并跳过 |
| 状态只存在进程里 | 重启后无法判断哪些格子已完成 | 幂等键（格名）+ 已完成集合放在外部存储；重复执行不得改变结果 |
| 常驻进程 | 容器永远不空闲，持续占用额度/计费 | 批处理任务**跑完即退出**；确需常驻时显式设开关并提供总时长上限 |
| 配置传递被分隔符拆散 | 列表型配置（如 `128,256,512`）只生效第一个 | 用不会被列表内部使用的分隔符（如 `;`）传多条配置；列表型值直接作为独立环境变量注入 |

另外两条与结果正确性有关：

- **每格结果与"格名"一起落盘**，不要只写一个聚合文件：聚合文件会被后一次运行覆盖，前面几格直接丢失（真实踩过：A、B 两格的指标被后一轮覆盖，只剩 C、D、E）。
- **重跑要能证明是同一格**：固定种子并把种子写进结果；同一格重跑出现不同数字，先查数据/环境，别急着当噪声。

## 交付物

- 每个审计一个包：`SPEC`（预登记判据 + 判决 + 诚实边界）、`MANIFEST`（机器可读的 claim/方向/基线/结果）、`metrics.json`（逐 seed）、单测（判据与数据划分的可执行校验）。
- 文稿里的数字从实验产物**直读**（脚本化改写），不手抄；改口径时同步改文稿的每一处。
- 报告三态：通过 / 未通过 / 未运行；未通过要写清推翻了哪条主张——包括推翻自己写的判据。
