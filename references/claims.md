# 让声明站得住：设计 → 检验 → 加固

**规则：相对增益只是测量结果，不是机制证据。**

一条主张要能被第三方接受，三段时间都得做对。本文按时间排序——**前一段没做对，后一段的精致都是浪费**。

| 段 | 问题 | 最便宜的失败点 |
| --- | --- | --- |
| **A 跑之前** | 对照设计对了吗 | 基线太弱 |
| **B 跑之后** | 这个数字能信吗 | 没有自检，分不清"没信号"与"实现错了" |
| **C 跨实现** | 换个实现还在吗 | 重跑同一份代码 |
| **D 报告** | 别人能复核吗 | 三态混写 |

（"这份产物是不是那次运行的"是另一个问题，见[证据完整性](evidence-integrity.md)。

---

## A. 跑之前：对照设计

### A1 平凡基线是阶梯，不是一档

"预测全零"只是最弱的一档，**零参数对照里还有更强的：预测训练集的类别均值**。

目标若是块状 one-hot（每样本恰有一个宽度 `d/K` 的区段置 1），两条基线都是**精确等式**：

| 零参数预测器 | 解析 MSE |
| --- | --- |
| 恒输出全零 | `1/K` |
| 每维输出类别均值 `1/K` | `(K−1)/K²` |

`K=6`：`0.1667` vs `0.1389`（差 20%）。实测某机制得 `0.1617`——
**比全零好 3.0%，但比预测均值差 16.4%**。用全零当基线会得到"低于基线"的错结论。

- 报基线至少两档：**全零/多数类** 与 **无参数最优常数**。
- 能解析算的就写解析值（进产物，不靠跑）——它不会被实现细节污染。
- 换损失函数时基线要跟着换；便宜的交叉校验：某档的"无信息预测"应与另一档解析基线**撞到同一个数**。

### A2 四类伪影

| 伪影 | 典型表现 | 决定性对照 | 判读 |
| --- | --- | --- | --- |
| ① **冻结/未训练组件** | 被声称承担收益的空间/对齐器/适配器从未被优化 | 审计**实际可训练参数集**，再跑"该组件可训练"的对照臂 | 可训练后增益消失 → 来自拟合能力，不来自被声称的机制 |
| ② **退化任务** | 标签本身就是捷径属性：来源、域、模态、架构 id | **标签置换**：无不动点置换，难度不变、只改标签对应 | 增益不变（±10pp 内）→ 度量的是"识别来源" |
| ③ **模型没用目标** | 输出与目标无关，却仍"赢"过基线 | **目标随机化**：逐样本给随机标签 | held-out **逐位相同** → 从未使用目标 |
| ④ **缺平凡基线** | 只报相对增益 | 加全零/多数类 **且** 无参数最优常数（A1） | 绝对误差须显著低于最强零参数基线 |

顺序：④ → ① → ②③ → 再谈机制。**③ 最便宜**（一行改标签），先做。
不同臂给出逐位相同的数字通常不是缺陷，而是"该变量没被用到"的诊断。

### A3 尺子本身会有盲区

MSE 是**点估计**：对"这个模型根本没在建模分布"没有分辨力。实测两个都很差的模型，
MSE 上只差几个百分点，而其中一个是纯常数预测器。

把评价器从一个变成三个，**配对**跑：

| 档 | 额外参数 | 能给出 |
| --- | --- | --- |
| MSE（对照） | 0 | 与历史读数可比 |
| 高斯 NLL（逐样本标量 `logvar`） | `d+1` | 分布拟合、可校准性 |
| Cross-Entropy | +1（温度） | 类别后验、准确率 |

四条纪律：

1. **配对**：三档共用同一 seed、初始化、批顺序；产物里落**初始化哈希**，从产物层证明（见 C2）。
2. **参数等量**：输出头尺寸会悄悄改变参数量。CE 用**块均值池化**（无参数），NLL 用逐样本标量方差（逐维对角会 `+d·h`）。
3. **构造跨档可比的标量**：三档 loss 量纲不同、**不可直接互比**；每档额外报"同一输出张量经各自头之后的 MSE"。
4. **输出落在同一几何上**：CE 不约束幅度，直接取它的 `mse` 会差一个数量级（实测 `1.97` vs `0.153`）。压到单纯形（块均值 → softmax → 摊回）后才可比。

两条判读：

- **`concat + 线性` 与 `add` 头数学等价**（都等于 `f(h)+g(c)`），解不了 XOR。实测 `linear` 0.492（=随机），`mlp` 宽度 **2** 即 1.000。所以"concat 有用"必须写成"**concat 之后的非线性**有用"。
- 方差头若训练集 `+0.96`、留出集 `−0.24`（反号），说明学的是训练集噪声结构 ⇒ 该档读数降权。

### A4 容量类读数必须与样本量一起报

| 混杂 | 症状 | 处置 |
| --- | --- | --- |
| **n 太小** | `n=512` 上"2560 维只占 33.7 个方向（1.32%）"；`n` 扫 64/128/256/512 得 20.8/24.7/29.8/33.7，**单调上涨未饱和** | 报秩必须给 `n` 并做 ≥3 档扫描；未饱和不能说"上限" |
| **组件被冻结** | 取出预训练特征后不再变，测出的秩是**预训练压缩的结果**，不是"空间"的属性 | 要让"空间能不能长"可测，被测组件须参与训练，且在**等参数**下比宽度 |

- **有效秩口径要写清**：参与率 `(Σσ)²/Σσ²` 与熵有效秩 `exp(−Σp log p)` 对长尾敏感度不同。两者都报，并报"占环境维的比例"——"秩=7"在 96 维与 3072 维下意思完全不同。
- **极小样本上相关度量会系统性虚高**：`n≈d` 时朴素 CCA 在**纯独立**随机块上给出 **29–31** 个"显著"通道（白化把样本噪声白成信号）。置换零分布有 `+1` 偏差，z 检验会把噪声读成 17。解法：互协方差谱 + **解析噪声水平**（按列标准化后独立时 `σ = 1/√(n−1)`）+ 谱的最优硬阈值；**纯噪声必须给 0 个通道**，写进单测。

## B. 跑之后：数字能不能信

### B1 管线自检：先在已知答案上跑通

真实数据给出"不显著"时，你无法区分三种情况——**真的没效应 / 实现有 bug / 数据坏了**。

**构造**：在同一条代码路径上先复现一个**已经确立的数字**。
实例：做 RSA 前先在已知数据上跑 200 类解码，得 **0.0785 = 15.7× 随机**，
与代码文档记载的 **15.6×** 一致 ⇒ 解码器是对的 ⇒ 此后"不显著"只可能是 RSA 或数据。

- **自检必须端到端**，不是零件测试。实测：零件全绿，接进管线后暴露 **4 个形状 bug**。
- **期望值须独立来源**（文档/论文/上一版产物），不能自己算一个再自己对。
- 自检失败时**先修实现，不要先解释数据**——反过来做会把 bug 写成科学发现。

副产品常常顺手证明别的事：上例的逐窗剖面（5.0× / **10.3×** / 8.8× / 1.0×）是教科书式刺激锁定，
同时确认了时间轴起点正确。

### B2 参照系：先找到分母

`R² = 0.0196` 是大是小？找一个**同类问题的公认上界**，把绝对数字变成比值。
实例：用其余 9 个被试的脑响应预测本被试 ⇒ **BBB 跨被试上限**，报 `img/BBB = 1.03`
⇒ 模型特征已达"另一个人的大脑"水平。

| 来源 | 例 | 注意 |
| --- | --- | --- |
| **同问题的物理上界** | 跨被试预测、分半信度上限 | **上界本身必须为正**，否则是管线错误 |
| **更强的同类方法** | 更大模型、更长训练 | **打平也是结论** |
| **被替换掉的旧实现** | 上一版脚本 | 必须同一口径 |

- **上界为负 = 管线坏了，不是"没信号"**。BBB 为负说明对齐失败，此时任何"显著性"都不可信。
- **"更强方法打平"是正面结论**：ViT-H-14 vs ViT-B-32 在脑解码上打平 ⇒ **144× 计算量换不来更好的脑解码**。

### B3 零分布：随机必须真的随机

置换看起来是"非随机"检验，但有效性完全取决于**置换的是不是该置换的东西**。

| 写法 | 症状 | 根因 |
| --- | --- | --- |
| 置换**数据行** | 置换值与原值**完全相同**（都是 0.0515） | 下游按位置重建标签 ⇒ 把置换撤销了 |
| 置换**组内数值**（测离散度） | `ratio` 精确 **1.00**、`p` 精确 **1.000** | 组内标准差对组内置换**不变** |

- 置换的对象必须是**产生结论的那个对应关系**。测"标签能否预测"就置换标签；测"分组是否影响离散度"就置换**分组**（伪标签）。
- **置换后与原值逐位相同 ⇒ 置换无效**，不是"没有差异"。这是最强的自检信号。
- **零分布口径必须与观测口径一致**。实测：观测是 `max_over_windows`，若零分布固定在"观测选中的那个窗"，窗口选择的向上偏置只作用在观测值上，p 偏乐观。**零分布也取 max**（一次矩阵解本就给出全部窗口，不额外花钱）。
- **报 p 必须报置换次数**：`p=0.005` 在 200 次下是**最小可能值**；`p=0.048` 在 20 次下同理。

### B4 等价性：证明"在哪算都一样"

结果跑在远端、分段执行、多台机器、多个实现。凭什么说等价？

| 机制 | 做法 |
| --- | --- |
| **判决冻结** | 判决脚本按 **SHA-256 校验后原样执行**；改的只能是"取哪些数据""怎么合并" |
| **随机数派生固定** | 判决内所有随机数由**固定 seed** 派生，**与样本名无关** ⇒ 同一单元在任何机器上逐位相同 |
| **三重交叉验证** | ① 同一单元在两个不同 Job 各算一遍 → 逐位相同（`+1.8144886303238472`）② 两种 worker 实现 → 与单跑日志一致 ③ **离线重算**（用判决里的 `decide()` 从原始记录重算）→ 与云端**逐字一致** |

⇒ **分段执行与整轮执行逐位等价**。这句话一旦成立，"平台中途取消长 Job"就不再是风险。

通用化：**判决是纯函数 + 随机数由内容派生 + 可离线重算** ⇒ 分段/分布式/重试皆等价。

## C. 跨实现：结论还在吗

### C1 独立复算：换实现，不是重跑

重跑同一份代码只能查"可复现"，查不出"被实现细节带偏"。**每审换掉全部自由变量**：

| 维度 | 一审 | 二审 | 三审 |
| --- | --- | --- | --- |
| 数据划分 | 换扰动种子 | 未见组合（奇偶划分） | **换域**（槽位值域分割） |
| 探针 | SGD 逻辑回归 | 闭式岭回归 | 岭回归 + MLP + kNN 三族 |
| 被替换的结构件 | 两层 MLP | LayerNorm+GELU MLP | 残差 MLP + 门控 |
| 种子 | 0–4 | 1000–1004 | 2000–2004 |
| 容量 | 256 | 128/256/512 | 96/384（与上一审不重叠） |

- 换种子不是形式：把"结论依赖某次初始化"变成可检验（≥4/5 同向）。
- 容量不重叠顺带测"结论是否只在某个容量成立"。
- 三套同向 → 可说"经三套独立实现复现"；**仍不要**写"已证明"。

### C2 配对：让差异只来自被研究的那个变量

多档并列比较时，**所有档共用同一初始化、同一批顺序、同一 seed**，产物里落**初始化哈希**。

实测收益：三档共用后读数 `0.1504 / 0.1507 / 0.1500`（差 **<0.5%**）——差异只能来自损失。
不配对时，同样的差异会被采样噪声淹没。

**参数等量**是另一半：换任何组件都可能悄悄改变参数量。判据：对着**真实模块**数参数并对齐到 **<1%**
（公式极易漏项：实测漏 `h²` 项偏差 **44%**、输出层重复计数偏差 **6.4%**，两次都被单测抓到）。

### C3 探针纪律

- **单一探针族不是证据**：线性探针读不到非线性可解码的结构（实测 MLP 0.58 vs 线性 0.43）。至少两类（线性 + 非线性/非参数），并报**差值**。
- **同时探"捷径属性"与"目标属性"**，不要只报高的那个。
- 探针自带自检：可分数据上应高、纯噪声上应接近随机；两者都报。
- 探针自己要训参数时必须在 `no_grad` **之外**；优先**闭式解**（岭回归）以便确定性复算。

### C4 正面控制：负面结论需要一条正面量

只证明"这个增益是假的"会被读成"什么都没做成"。若声称"共享空间让异构表示相遇"，就直接量它：

| 空间 | 跨分支一致性（余弦） |
| --- | --- |
| 冻结随机 | +0.01 / −0.01（彼此无关） |
| 学到的 | +0.54 / +0.61（确实相遇） |

配一条正面量，结论才是"收益来自空间、不来自融合"，而不是"什么都没做成"。

## D. 报告

- **三态分开写**：实现已修改 / 相关功能检查通过 / 评估指标改善。没有的检查不写成通过。
- **数字从产物直读**（脚本化改写），不手抄；改口径时同步改每一处。
- **剔除样本必须留痕**：哪个、为什么、依据哪条判据。静默剔除等于选择性报告。
- **判据自身会怎么错**（用错代理量 / 某些臂上不成立 / 方向写反）见[证据完整性 §3](evidence-integrity.md)。

## 这些检查实际抓到了什么（量级参照）

同一项目连续六代的审计结果：

| 代 | 被审计的主张 | 判决 |
| --- | --- | --- |
| 一审 | "融合优于最优单专家 +26.7%，留出仍成立" | margin 是**源身份识别**的产物：源可解码 1.000 vs 目标类别 0.279（随机 0.125）；绝对误差 4.74 是最弱平凡基线的 **38 倍** |
| 二审 | 换实现复算 | 冻结臂里"对齐/标签置换/**目标随机化**"三臂数字**逐位相同**（7.18/6.38/5.78）→ 从未使用目标；学到空间后 margin 归零、绝对误差降 ~100 倍 |
| 三审 | 再换实现 + 正面量 | 目标置换 margin 变化 **0.0 个百分点**；有意义空间 margin −0.2%/−0.4%；跨分支一致性 +0.01 → **+0.54/+0.61** |

可辩护的弱主张（比原主张更有用）：**共享空间必须有意义，异构融合才可能工作；一旦空间有意义，融合相对"用好其中一个"优势很小。**
