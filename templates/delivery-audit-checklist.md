# 交付前勾选清单

> **只做勾选，不重复填写内容。** 判据、阈值、实测数字都在[预登记表](audit-preregistration.md)里。
> 仅勾选实际核查的项目；写明不适用理由；未执行、失败、阻塞、通过四态分开标注。
> 按任务裁剪——**清单存在不等于检查已完成**。

## 变更边界

- [ ] 有开始前状态记录；已审查完整 diff / 文件清单，确认仅含本任务改动。
- [ ] 用户已有改动保留；本轮没有未经说明地覆盖、清理或回退其他内容。
- [ ] 最终 `git status` 已检查（若用 Git）；否则用开始前清单/快照比对，**未声称检查过 Git**。
- [ ] 没有意外生成物、临时 checkpoint、缓存、大体积数据或未交付文件。

## 架构与权重

- [ ] 框架/版本结论已分层（依赖 / 配置 / 静态可达 / 本次观测），并写明覆盖边界。
- [ ] 改动的模块**实际进入**目标 forward/图/导出路径；输入输出契约、shape、dtype/device、mask/状态已按适用性验证。
- [ ] 新参数/buffer 的注册、保存加载、初始化已核实；**只在适用的训练参数上**检查梯度与 optimizer 纳入。
- [ ] checkpoint 的来源、revision、分片与校验依据已记录；安全加载路径已审查。
- [ ] 权重逐项分类（复用/映射/初始化/重置/排除）与 `missing/unexpected/mismatch` 已按[兼容性标准](../references/checkpoint-compatibility.md)解释；同名同形已另核语义。
- [ ] optimizer / scheduler / RNG / shard / 量化元数据 / KV cache 状态已按适用性保留、转换或重置，理由明确。

## 验证证据

- [ ] 基线与候选使用同一固定任务/夹具、有效配置与可比资源；评估门槛有**预先**依据。
- [ ] 每项核心改动先过覆盖该行为面的最小检查；失败后复跑同一用例；交付前重跑固定回归集。
- [ ] 已记录实跑命令、退出码、环境/设备、数据与权重版本、seed、重复次数、指标波动。
- [ ] 已区分**结构/路径正确**、**权重/数值兼容**、**任务质量改善**、**效率改善**；无相应实测时不声称提升。
- [ ] 特殊路径（分布式 / 量化 / cache / 导出 / 编译）有对应验证；单路径结果未冒充其他路径通过。
- [ ] mock / 沙箱 / 离线 / 真实端到端**分别标注**；未运行、失败、跳过、阻塞项均显式列出。

## 安全与交付

- [ ] 代码、测试、fixtures、日志、产物中没有密钥、令牌、个人数据或不必要敏感信息。
- [ ] 运行路径的网络、凭据、文件/生产写入、外部服务、构建钩子、动态代码等副作用已审查并受控；未授权高影响操作未执行。
- [ ] 交付包含可复现命令/固定配置摘要与产物位置；不包含秘密值。
- [ ] 已写明版本、设备、分支、输入、trace 完整性与环境限制；建议的下一步与证据边界匹配。
